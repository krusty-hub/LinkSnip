# LinkSnip

LinkSnip is a modern, fast link management and shortening service with real-time analytics, custom aliases, and link expiration.

## Features

- **Link Shortening**: Quickly create short, clean links.
- **Custom Slugs**: Custom aliases for branded links.
- **Expiration Controls**: Set optional expiration dates for time-sensitive links.
- **Analytics & Tracking**: Track click metrics and referrer data.
- **Responsive UI**: Clean, professional interface built with Tailwind CSS and Radix UI.

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm

### Installation

```bash
npm install
```

### Development

Start the development server:

```bash
npm run dev
```

### Build & Production

Build the application for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

### Testing & Linting

```bash
npm run test        # Run unit tests
npm run test:watch  # Run tests in watch mode
npm run lint        # Check code quality
npm run format      # Format source code
```
